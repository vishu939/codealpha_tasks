# Student Grade Tracker (Java Project)

## 📌 Task 1
This project is built as part of an internship assignment.  
It allows managing student grades with the following features:
- Input and manage student grades
- Calculate average, highest, and lowest scores
- Store data using ArrayList
- Display a summary report of all students
- Console-based interface

This project is a Java-based AI chatbot developed for real-time interactive communication.

Features
Java-based chatbot
NLP text preprocessing
Tokenization
Intent detection
Rule-based responses
FAQ responses
Java Swing GUI
Real-time interaction
Technologies Used
Java
Java Swing
NLP techniques
Rule-based system
How to Run
Clone this repository.
Open the project in IntelliJ IDEA or Eclipse.
Open Main.java.
Run Main.java.
The chatbot GUI will open.
