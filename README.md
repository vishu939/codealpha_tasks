# Student Grade Tracker (Java Project)

## 📌 Task 1
This project is built as part of an internship assignment.  
It allows managing student grades with the following features:
- Input and manage student grades
- Calculate average, highest, and lowest scores
- Store data using ArrayList
- Display a summary report of all students
- Console-based interface
